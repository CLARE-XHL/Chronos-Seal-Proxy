Chronos Seal Proxy 在线运行

零知识“盲代理”授权中转服务器

本服务器是 Chronos Seal GUI 的 OAuth 授权中继。它的唯一使命是帮助本地 GUI 安全地换取访问 GitHub 的临时令牌（Access Token），全程不存储任何用户数据。

🛡️ 核心安全承诺

  • 绝对不存储数据：无数据库，函数执行完毕后立刻销毁。
  • 绝对不接触种子：用户的加密密钥完全在本地生成，并直接发送至 GitHub。
  • 绝对不访问私人仓库：仅被授权操作您 Fork 出来的模板仓库。
为什么访问根目录会看到这个页面？
这是一个纯 API 端点（Endpoint），不提供网页服务。当您看到这个页面时，说明中转服务器正在正常运行，随时准备为您换发安全令牌。
